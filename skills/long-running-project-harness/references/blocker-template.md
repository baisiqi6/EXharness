# Blocker Template

当同一问题连续 3 次尝试没有推进时，停止继续试错，填写这个文件。

```markdown
# Blocker

## Item

- Checklist item:
- Owner:
- Session:
- Updated at:
- Event:
- Unblock owner:

## Problem

当前卡住的具体问题是什么。

## Impact

- 阻塞了什么
- 影响哪个 checklist item

## Attempts

1. 尝试了什么
   结果：
2. 尝试了什么
   结果：
3. 尝试了什么
   结果：

## Evidence

- 关键错误信息：
- 相关文件：
- 相关命令：

## Current Hypothesis

目前最怀疑的原因是什么。

## Recommended Next Step

- 你建议下一个 agent 或用户怎么接手。

## Handoff

- 可以直接发给审查者或第二视角 agent 的最小上下文摘要。
```
